# 집필 문서 안내

책을 쓰는 학생과 집필을 돕는 AI가 함께 참고하는 문서다. 문서는 다음 순서로 읽는다.

| 문서 | 역할 | 사용할 때 |
| --- | --- | --- |
| [TOPICS.md](../TOPICS.md) | 장과 꼭지의 범위 및 담당 | 자기 꼭지와 같은 장의 구성을 확인할 때 |
| [CONTRIBUTING.md](../CONTRIBUTING.md) | 원문 언어, 담당 파일과 PR 절차 | 집필을 시작하고 초안을 제출할 때 |
| [WRITING_STYLE.md](WRITING_STYLE.md) | 공통 집필 기준, 출처 표기와 리뷰 구분 | 본문을 작성하고 검토할 때 |
| [AI_PROSE_CHECKLIST.md](AI_PROSE_CHECKLIST.md) | 교수님이 제공한 문체 점검 참고 목록 | 초안 제출 전 자기 점검과 이후 문체 편집을 할 때 |
| [AGENTS.md](../AGENTS.md) | AI의 수정 범위와 저장소 작업 지침 | AI와 원고를 작성하거나 수정할 때 |
| [CLAUDE.md](../CLAUDE.md) | 공통 에이전트 지침을 불러오는 파일 | Claude Code로 작업할 때 |
| [SYLLABUS.md](../SYLLABUS.md) | 수업 운영과 AI 사용 정책 | 수업의 기여 요건과 정책을 확인할 때 |

## 초안부터 제출까지

TOPICS.md에서 담당과 범위를 확인하고, CONTRIBUTING.md에 따라 작업을 시작한다. WRITING_STYLE.md를 기준으로 원고를 작성한 뒤 AI_PROSE_CHECKLIST.md를 참고해 자기 점검한다. 출처와 실행 결과를 직접 확인하고 초안 PR을 공유한다. 사용하는 AI에도 AGENTS.md와 docs/WRITING_STYLE.md를 함께 제공한다.

## 두 단계의 문체 점검

학생은 초안 단계부터 표현을 스스로 점검한다. PR에서는 WRITING_STYLE.md의 필수 기준과 문체 제안을 구분한다. 참고 목록의 모든 표현을 일괄 삭제하거나 모든 꼭지를 같은 형식으로 맞추지 않는다.

초안이 모이면 조장이 장 전체의 내용과 연결을 점검하고 티칭 팀과 함께 중복, 개념 사전과 상호참조를 정리한다. 내용 정리 뒤 장 단위로 문체를 다듬으며, 편집한 문장도 저자가 확인한다. 저자의 주장이나 해석이 달라지는 변경은 해당 저자의 확인을 받는다.

책 소개와 읽기 링크는 [루트 README](../README.md)에 있다.
